# FIFA World Cup 2026 Analytics

Statistical analysis and linear regression project on the 2026 FIFA World Cup
(Canada / Mexico / USA, 11 June – 19 July 2026).

See [`wc2026-analysis/`](wc2026-analysis/) for the full project: data, notebooks,
source code, and the written report.

Quick start:

```bash
cd wc2026-analysis
pip install -r requirements.txt
jupyter notebook notebooks/
```
