# FIFA World Cup 2026 Analytics

```
python wc2026_analytics.py
```

Needs `fifa data.xlsx` in this folder (sheets: matches, teams, players). Writes `wc2026_report.html`.

`WC2026_3min.pptx` — 8-slide briefing with the report charts. Read `PRESENTATION_SCRIPT.md` (same text is in PowerPoint Presenter View).
